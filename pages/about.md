### 关于博客

本博客基于 [Jekyll](https://jekyllrb.com/) 构建，纯静态站点，轻量且高效。

**技术栈：**

| 类别 | 说明 |
| --- | --- |
| 站点生成 | Jekyll 3.8.5 |
| 代码高亮 | Rouge 3.11.0 |
| 前端 | 原生 HTML / CSS / JS |
| 资源优化 | esbuild 生产构建压缩 |
| 部署 | GitHub Pages Actions |

**主要特性：**

- 响应式布局，适配手机、平板和桌面
- 明暗主题切换，可点击页头头像或右下角主题按钮
- 客户端站内搜索，无需后端服务
- 分类归档，按年份和分类整理文章
- 文章目录：桌面端固定在右侧，非桌面端从右下角展开
- 代码高亮、一键复制和图片全屏预览
- MathJax 数学公式与 Mermaid 图表渲染，脚本本地按需加载
- 文章二维码，手机扫码即可打开当前文章
- PWA 离线缓存支持
- 文章 URL 基于源文件 MD5 生成，资源仍按日期目录访问
- 生产构建自动压缩 JS / CSS，并去除产物注释
