### 加密函数

| 函数          | 说明       |
|---------------|------------|
| `MD5('密码')` | 不可逆加密 |
| `SHA('密码')` | 不可逆加密 |

### 信息函数

| 函数                                                             | 说明                                    |
|------------------------------------------------------------------|-----------------------------------------|
| `VERSION()`                                                      | 当前 MySQL 版本号                       |
| `CONNECTION_ID()`                                                | 当前服务器连接数                        |
| `DATABASE()` / `SCHEMA()`                                        | 当前所在数据库                          |
| `USER()` / `CURRENT_USER()` / `SYSTEM_USER()` / `SESSION_USER()` | 当前连接用户名（格式：`用户名@主机名`） |
| `CHARSET(value)`                                                 | 字符串的字符集                          |
| `COLLATION(value)`                                               | 字符串的比较规则                        |

### 其他函数

| 函数                             | 说明                              |
|----------------------------------|-----------------------------------|
| `FORMAT(value, n)`               | 数字格式化，四舍五入保留 n 位小数 |
| `CONV(value, from, to)`          | 进制转换                          |
| `INET_ATON(ip)`                  | IP 地址转数字                     |
| `INET_NTOA(value)`               | 数字转 IP 地址                    |
| `BENCHMARK(n, expr)`             | 表达式执行 n 次，测试耗时         |
| `CONVERT(value USING char_code)` | 修改字符编码                      |
