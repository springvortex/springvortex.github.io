### 关键字

| 关键字 | 说明         |
|--------|--------------|
| `IN`   | 在集合中     |
| `ANY`  | 满足任意一个 |
| `ALL`  | 满足全部     |
| `SOME` | 同 `ANY`     |

### 示例：查询平均工资最低的部门

**方式一**：子查询嵌套

```sql
SELECT department_id
FROM employees
GROUP BY department_id
HAVING AVG(salary) = (
    SELECT MIN(avg_sal)
    FROM (
        SELECT AVG(salary) avg_sal
        FROM employees
        GROUP BY department_id
    ) t_dept_avg_sal  -- 子查询结果需取别名
);
```

**方式二**：使用 `ALL` 简化

```sql
SELECT department_id
FROM employees
GROUP BY department_id
HAVING AVG(salary) <= ALL (
    SELECT AVG(salary)
    FROM employees
    GROUP BY department_id
);
```

### 注意事项

- **空值问题**：注意除以 `NULL` 的场景
- `(NOT) EXISTS`：相关子查询判断是否存在
- **相关更新** / **相关删除**：子查询引用外部表
