> SpringBoot 摒弃 XML 配置方式，改为 **全注解驱动**。

### 注册组件的方式

1. `@Configuration` 编写一个配置类
2. 在配置类中，自定义方法给容器注册组件，配合 `@Bean`
3. 使用 `@Import` 导入第三方组件

### 示例对比

**XML 方式（旧）：**

```xml

<bean id="user" class="com.example.boot.bean.User">
    <property name="id" value="1"/>
    <property name="name" value="zhangsan"/>
</bean>
```

**注解方式（新）：**

```java

@Configuration
public class AppConfig {

    @Bean
    public User user() {
        User user = new User();
        user.setId(1L);
        user.setName("zhangsan");
        return user;
    }
}
```
