> 下载地址/官网：[Eclipse Temurin JDK 21](https://adoptium.net/temurin/releases/?version=21)

JDK 21 是这套 Spring Cloud Alibaba 微服务的运行基线。Gateway、Provider、Consumer、Mail 都是 Java 服务，Nacos 和 Zipkin
也建议直接跑在 JDK 21 上。本文按三个系统分别安装，最后确认 `java` 命令可用。

> 先确认系统架构：普通 Intel/AMD 电脑选 x64，Apple Silicon 的 Mac 选 ARM64。不要按“最新版本”盲装，先认准大版本 21。

### 安装目标

安装完成后，在终端执行下面命令，能看到 `21` 开头的版本号即可：

```sh
java -version
```

期望输出类似：

```text
openjdk version "21.0.x" 2026-xx-xx
OpenJDK Runtime Environment Temurin-21.0.x
OpenJDK 64-Bit Server VM Temurin-21.0.x
```

### Windows 安装 JDK 21

1. 打开 [Eclipse Temurin 21 下载页](https://adoptium.net/temurin/releases/?version=21)。
2. 在 `Operating System` 选择 `Windows`，`Machine Architecture` 选择自己电脑的架构，一般是 `x64 / JDK`。
3. 下载 `.msi` 安装包，例如 `OpenJDK21U-jdk_x64_windows_hotspot_21.0.x_x.msi`。
4. 双击安装包，一路下一步。到 `Custom Setup` 页面时，建议勾选：

```text
Add to PATH
Associate .jar files with Java
Set JAVA_HOME variable
```

5. 点击 `Install`，等待安装完成。
6. 重新打开一个 PowerShell。一定要重新打开，旧窗口不会自动拿到新的环境变量。
7. 验证安装：

```powershell
java -version
where.exe java
```

第一条能看到 21 开头的版本号，第二条能看到 `java.exe` 的完整路径，就说明安装成功。

#### Windows 手动配置 JAVA_HOME

如果安装时没有勾选 `Set JAVA_HOME variable`，可以手动补：

1. 按 `Win` 键，搜索“编辑系统环境变量”，打开后点击 `环境变量`。
2. 在“系统变量”里点击 `新建`。
3. 变量名填：

```text
JAVA_HOME
```

4. 变量值填 JDK 安装目录，例如：

```text
C:\Program Files\Eclipse Adoptium\jdk-21.0.x
```

5. 找到 `Path`，确认里面有 `%JAVA_HOME%\bin`，或者直接有 `C:\Program Files\Eclipse Adoptium\jdk-21.0.x\bin`。
6. 连续点击确定，重新打开 PowerShell 后验证。

> 目录里的 `21.0.x` 要换成你实际安装的版本号。配置环境变量时选择到包含 `bin` 目录的上一层，不要把路径配到 `bin` 里面。

### Ubuntu 安装 JDK 21

Ubuntu 22.04、24.04 可以直接使用 apt 安装 OpenJDK 21。

1. 更新软件源：

```bash
sudo apt update
```

2. 安装 JDK 21：

```bash
sudo apt install -y openjdk-21-jdk
```

3. 验证：

```bash
java -version
```

4. 查看安装路径：

```bash
sudo update-alternatives --list java
```

常见路径是：

```text
/usr/lib/jvm/java-21-openjdk-amd64/bin/java
```

因此 `JAVA_HOME` 通常配置为：

```text
/usr/lib/jvm/java-21-openjdk-amd64
```

5. 如果某些脚本必须依赖 `JAVA_HOME`，可以编辑 `/etc/environment`：

```bash
sudo vim /etc/environment
```

追加一行：

```text
JAVA_HOME="/usr/lib/jvm/java-21-openjdk-amd64"
```

保存后重新登录 SSH，或者重启服务器。

#### Ubuntu 多版本切换

如果机器上同时安装了 JDK 17、21 等多个版本，可以切换默认 `java`：

```bash
sudo update-alternatives --config java
```

输入 JDK 21 对应的编号，回车后再执行 `java -version` 确认。

### macOS 安装 JDK 21

macOS 推荐用 Homebrew 安装 Temurin 21。

1. 如果没有 Homebrew，先安装：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

2. 安装 JDK 21：

```bash
brew install --cask temurin@21
```

3. 验证：

```bash
java -version
```

4. 查看 JDK 21 的安装目录：

```bash
/usr/libexec/java_home -v 21
```

5. 如果需要设置 `JAVA_HOME`，编辑 `~/.zshrc`：

```bash
vim ~/.zshrc
```

追加：

```sh
export JAVA_HOME=$(/usr/libexec/java_home -v 21)
export PATH="$JAVA_HOME/bin:$PATH"
```

6. 让配置立即生效：

```bash
source ~/.zshrc
```

7. 验证环境变量：

```bash
echo "$JAVA_HOME"
java -version
```

### 常见问题

#### 提示 java 不是内部或外部命令

通常是 PATH 没生效。Windows 重新打开 PowerShell；Ubuntu 和 macOS 重新登录终端。如果还是没有，检查 JAVA_HOME 是否配置到了
`bin` 里面。

#### 版本显示的不是 21

说明机器上有多个 JDK，PATH 优先级不对。Windows 在“环境变量”里把 JDK 21 的 `bin` 上移；Ubuntu 用 `update-alternatives`；macOS
用 `JAVA_HOME` 明确指定版本。

#### Nacos 或 Zipkin 启动失败

先在同一个终端执行 `java -version`。如果终端显示的是 21，但服务脚本找不到 Java，通常是服务运行用户的环境变量没配置。Ubuntu
可以在服务配置里显式写入 `JAVA_HOME`，或者确认 `/usr/bin/java` 指向 21。

### 部署清单

安装完成后，记下这台机器的 Java 环境：

```sh
java -version
echo "$JAVA_HOME"
```

这套微服务的生产部署顺序一般是：先装 JDK 21，再装 MySQL、Nacos、Zipkin，最后启动业务服务。JDK 是所有 Java 进程的地基，建议最先装好。
