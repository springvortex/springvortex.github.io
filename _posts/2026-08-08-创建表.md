### 数据库操作

```sql
CREATE
DATABASE 库名;                          -- 使用默认字符集
SHOW
DATABASES;                                -- 查看所有数据库
CREATE
DATABASE 库名 CHARACTER SET 'utf8mb4';   -- 指定字符集
USE
库名;                                       -- 切换数据库
SHOW
TABLES;                                    -- 查看当前库的表
ALTER
DATABASE 库名 CHARACTER SET 'utf8mb4';    -- 修改字符集
DROP
DATABASE IF EXISTS 库名;                   -- 删除数据库
```

> 尽量不要修改数据库名。

### 创建表

```sql
CREATE TABLE IF NOT EXISTS 表名
(
    id
    INT,
    name
    VARCHAR
(
    50
),
    hire_date DATE
    );
```

#### 基于查询结果创建表

```sql
CREATE TABLE 新表名 AS
SELECT department_id AS 别名, name AS 别名
FROM employees;
-- 别名会成为新表的列名
```
