### 获取当前时间

| 函数        | 说明               |
|-------------|--------------------|
| `CURDATE()` | 返回年月日         |
| `CURTIME()` | 返回时分秒         |
| `NOW()`     | 返回系统日期和时间 |

### 时间戳转换

- `UNIX_TIMESTAMP()` / `UNIX_TIMESTAMP(date)`
- `FROM_UNIXTIME()`

### 提取日期信息

| 函数                                           | 说明                       |
|------------------------------------------------|----------------------------|
| `YEAR(date)` / `MONTH(date)` / `DAY(date)`     | 提取年月日                 |
| `HOUR(time)` / `MINUTE(time)` / `SECOND(time)` | 提取时分秒                 |
| `MONTHNAME(date)`                              | 返回月份名称（January...） |
| `DAYNAME(date)`                                | 返回星期名称               |
| `WEEKDAY(date)`                                | 返回周几                   |
| `QUARTER(date)`                                | 返回季度                   |
| `WEEK(date)` / `WEEKOFYEAR(date)`              | 一年中的第几周             |
| `DAYOFYEAR(date)`                              | 一年中的第几天             |
| `DAYOFMONTH(date)`                             | 一个月中的第几天           |
| `DAYOFWEEK(date)`                              | 一周中的第几天             |

### 日期运算

```sql
-- 加减指定间隔
DATE_ADD
(date, INTERVAL num type)
DATE_SUB(date, INTERVAL num type)

-- 时间差
DATEDIFF(a, b)   -- a 和 b 间隔多少天
TIMEDIFF(a, b)    -- a 和 b 间隔的时间
```

| 函数                  | 说明                          |
|-----------------------|-------------------------------|
| `ADDTIME(t1, t2)`     | 时间相加                      |
| `SUBTIME(t1, t2)`     | 时间相减                      |
| `FROM_DAYS(n)`        | 从 0000-01-01 算 n 天后的日期 |
| `TO_DAYS(date)`       | 日期到 0000-01-01 的天数      |
| `LAST_DAY(date)`      | 所在月份最后一天              |
| `MAKEDATE(year, day)` | 某年第 day 天的日期           |
| `MAKETIME(h, m, s)`   | 构造时间                      |

### 格式化

```sql
-- 日期转字符串
DATE_FORMAT
(date, format)

-- 字符串转日期
STR_TO_DATE(str, format)
```

#### format 占位符

| 占位符             | 说明                             |
|--------------------|----------------------------------|
| `%Y` / `%y`        | 4 位 / 2 位年份                  |
| `%M` / `%m` / `%c` | 月名 / 2 位月数 / 月数           |
| `%d` / `%e`        | 2 位天数 / 天数                  |
| `%H` / `%h`        | 24 小时制 / 12 小时制            |
| `%i`               | 分钟                             |
| `%S` / `%s`        | 秒                               |
| `%W` / `%a`        | 星期名 / 星期缩写                |
| `%j`               | 一年中的第几天                   |
| `%U` / `%u`        | 第几周（Sunday / Monday 为首日） |
