### 级别排序（由低到高）

`ALL` → `TRACE` → `DEBUG` → `INFO` → `WARN` → `ERROR` → `FATAL` → `OFF`

> 日志输出规则： **只会打印指定级别及比它优先级更高的日志**。

### 各级别说明

| 级别    | 说明                                             |
|---------|--------------------------------------------------|
| `ALL`   | 打印全部级别的所有日志                           |
| `TRACE` | 追踪框架运行的超详细流程，日常开发几乎不用       |
| `DEBUG` | 开发调试阶段的细节日志，打印中间变量、方法入参等 |
| `INFO`  | 记录关键业务节点、核心运行状态                   |
| `WARN`  | 警告，不影响运行但存在潜在风险                   |
| `ERROR` | 业务错误，程序异常、接口调用失败                 |
| `FATAL` | 致命错误，直接导致程序崩溃                       |
| `OFF`   | 完全关闭所有日志记录                             |

### 默认配置

- 没有单独指定级别的类，使用 **root 根配置**指定的级别作为默认
- Spring Boot 日志的默认初始级别是 **`INFO`**
