### 整数类型对照表

| 类型        | 字节数 | 无符号范围                     |
|-------------|--------|--------------------------------|
| `TINYINT`   | 1      | 0 ~ 255                        |
| `SMALLINT`  | 2      | 0 ~ 65,535                     |
| `MEDIUMINT` | 3      | 0 ~ 16,777,215                 |
| `INT`       | 4      | 0 ~ 4,294,967,295              |
| `BIGINT`    | 8      | 0 ~ 18,446,744,073,709,551,615 |

### 补充说明

- `INT(n)` 中的 n 表示 **显示宽度**，后面可接 `ZEROFILL` 补零
- `UNSIGNED` 表示 **无符号**，即只有正数和零
