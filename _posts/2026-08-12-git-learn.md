### git 克隆代码

```bash
git clone https://github.com/zhongruntao/zhongruntao.github.io.git
```

git clone + 要克隆的仓库地址

### git 拉取代码

拉取代码,即更新代码,把代码从远程仓库 (gitee/github)同步到本地 (windows)

```bash
git pull
```

### git 提交代码到本地暂存区

```bash
# 添加代码
# git add 需要提交的文件,(.)代表所有被修改的文件,例如提交本次修改的所有文件
git add .
# 填写本次提交的代码修改注释说明
git commit -m "注释"
```

### git 推送代码

推送代码之前必须拉取代码

```bash
git push
```

### git 查看修改的状态

```bash
git status
```

### git 查看提交历史

```bash
git log
```
