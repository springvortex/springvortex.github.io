### 修改表结构

```sql
-- 增加字段
ALTER TABLE 表名 ADD 列名 DOUBLE(总位数, 小数位);

-- 修改字段类型
ALTER TABLE 表名 MODIFY 列名 VARCHAR(50);

-- 重命名字段（可同时改类型）
ALTER TABLE 表名 CHANGE 旧列名 新列名 VARCHAR(50);

-- 删除字段
ALTER TABLE 表名 DROP COLUMN 列名;
```

### 重命名表

```sql
RENAME TABLE 旧表名 TO 新表名;
```

### 删除与清空

```sql
DROP TABLE IF EXISTS 表名;    -- 删除表
TRUNCATE TABLE 表名;          -- 清空表
```

### 数据操作

```sql
-- 插入多条数据
INSERT INTO 表名 (a, b, c) VALUES
    (1, 2, 3),
    (4, 5, 6);

-- 更新数据
UPDATE 表名
SET 列名1 = 新值, 列名2 = 新值
WHERE id = 5;    -- 定位
```
