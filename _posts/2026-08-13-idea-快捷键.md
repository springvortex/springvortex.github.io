### IntelliJ IDEA 常用快捷键大全

Windows系统默认快捷键，Mac用户将`Ctrl`替换为`Command`即可通用。

---

#### 一、全局搜索与定位

| 快捷键             | 功能说明                                       |
|--------------------|------------------------------------------------|
| 双击Shift          | 全局任意内容搜索，可搜类、文件、配置、操作命令 |
| `Ctrl + N`         | 快速搜索指定Java类，支持模糊匹配               |
| `Ctrl + Shift + N` | 搜索任意文件，包括配置文件、XML、资源文件      |
| `Ctrl + F`         | 当前文件内文本查找                             |
| `Ctrl + R`         | 当前文件内文本替换                             |
| `Ctrl + Shift + F` | 全局项目范围内搜索指定文本内容                 |
| `Ctrl + Shift + R` | 全局项目范围内批量替换指定文本                 |

---

#### 二、代码编辑与生成

| 快捷键             | 功能说明                                                          |
|--------------------|-------------------------------------------------------------------|
| `Alt + Insert`     | 自动生成代码，快速生成构造方法、Getter/Setter、toString、重写方法 |
| `Ctrl + /`         | 单行注释/取消注释，自动适配当前文件语言                           |
| `Ctrl + Shift + /` | 多行块注释/取消块注释                                             |
| `Ctrl + D`         | 快速复制当前选中行，无需手动粘贴                                  |
| `Ctrl + X`         | 剪切当前行，不用选中整行直接按就生效                              |
| `Ctrl + Y`         | 删除当前整行代码                                                  |
| `Shift + Enter`    | 在当前行下方新开一行，光标自动跳到新行开头                        |
| `Ctrl + Alt + L`   | 一键格式化当前文件所有代码，自动对齐缩进                          |
| `Ctrl + Alt + O`   | 自动优化导入，清理没用的冗余import语句                            |

---

#### 三、代码跳转与查看源码

| 快捷键                | 功能说明                                             |
|-----------------------|------------------------------------------------------|
| `Ctrl + 左键点击`     | 直接跳转到方法、类、变量的定义位置                   |
| `Ctrl + B`            | 跳转到定义处，和左键点击效果一致                     |
| `Ctrl + Alt + 左箭头` | 回到上一个光标停留的位置，看源码返回上一步超实用     |
| `Ctrl + Alt + 右箭头` | 前进到下一个光标停留的位置                           |
| `Ctrl + H`            | 查看当前类的完整继承层级树，显示所有父类和实现的接口 |
| `Ctrl + Shift + B`    | 跳转到接口方法的具体实现类，不用手动查找实现         |
| `Alt + F7`            | 全局查找当前方法/变量被哪些地方调用过                |

---

#### 四、调试与运行

| 快捷键        | 功能说明                                                   |
|---------------|------------------------------------------------------------|
| `Shift + F10` | 直接运行当前启动类/项目                                    |
| `Shift + F9`  | 以调试模式启动项目                                         |
| `F7`          | 调试时步入方法内部，进入方法逐行执行                       |
| `F8`          | 调试时步过，执行完当前行直接跳到下一行，不进入方法内部     |
| `Shift + F8`  | 调试时步出，直接从当前方法里跳出，回到调用这个方法的上一行 |
| `Ctrl + F2`   | 直接停止当前正在运行的程序/调试进程                        |
| `Ctrl + F8`   | 在当前行快速添加/取消断点                                  |

---

#### 五、项目与工具操作

| 快捷键                   | 功能说明                                               |
|--------------------------|--------------------------------------------------------|
| `Ctrl + Shift + F9`      | 一键重新编译当前修改的文件                             |
| `Ctrl + Shift + Alt + S` | 快速打开项目结构配置面板                               |
| `Ctrl + Shift + A`       | 全局搜索任意操作命令，忘记快捷键时直接搜功能名就能找到 |

---

#### 六、窗口与视图操作

| 快捷键             | 功能说明                               |
|--------------------|----------------------------------------|
| `Alt + 1`          | 快速打开/隐藏左侧项目文件树面板        |
| `Alt + 4`          | 快速打开/隐藏下方调试运行控制台面板    |
| `Ctrl + E`         | 弹出最近打开过的文件列表，快速切换文件 |
| `Ctrl + Shift + E` | 查看最近修改过的所有文件               |
