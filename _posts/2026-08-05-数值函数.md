### 基本函数

| 函数                   | 说明                    |
|------------------------|-------------------------|
| `ABS()`                | 绝对值                  |
| `SIGN()`               | 正数返回 1，负数返回 -1 |
| `PI()`                 | 圆周率                  |
| `CEIL()` / `CEILING()` | 向上取整                |
| `FLOOR()`              | 向下取整                |
| `LEAST()`              | 返回最小值              |
| `GREATEST()`           | 返回最大值              |
| `MOD()`                | 取余                    |
| `RAND(seed)`           | 随机数                  |
| `ROUND(x, d)`          | 四舍五入，保留 d 位小数 |
| `TRUNCATE(x, d)`       | 截断到 d 位小数         |
| `SQRT()`               | 平方根                  |

### 弧度换算

- `RADIANS()`：角度转弧度
- `DEGREES()`：弧度转角度

### 三角函数

`SIN()`, `COS()`, `TAN()`, `ASIN()`, `ACOS()`, `ATAN()` 等

### 指数与对数

- `POW(x, y)` / `POWER(x, y)`：x 的 y 次方
- `EXP(x)`：e 的 x 次方
- `LN()` / `LOG()`：自然对数

### 进制转换

| 函数            | 说明                        |
|-----------------|-----------------------------|
| `BIN()`         | 转二进制                    |
| `HEX()`         | 转十六进制                  |
| `OCT()`         | 转八进制                    |
| `CONV(a, b, c)` | 将 b 进制的 a 转换为 c 进制 |
