### 长度与编码

| 函数            | 说明                            |
|-----------------|---------------------------------|
| `ASCII()`       | 返回第一个字母的 ASCII 值       |
| `CHAR_LENGTH()` | 字符数（中文算 1 个字符）       |
| `LENGTH()`      | 字节数（UTF-8 中文算 3 个字节） |

### 拼接与替换

| 函数                            | 说明             |
|---------------------------------|------------------|
| `CONCAT(a, b, ...)`             | 连接字符串       |
| `CONCAT_WS(分隔符, a, b, ...)`  | 用指定分隔符连接 |
| `INSERT(str, pos, len, newstr)` | 在指定位置插入   |
| `REPLACE(str, old, new)`        | 替换             |

### 大小写转换

- `UPPER()` / `UCASE()`：转大写
- `LOWER()` / `LCASE()`：转小写

### 截取与填充

| 函数                    | 说明                         |
|-------------------------|------------------------------|
| `LEFT(str, n)`          | 从左侧取 n 个字符            |
| `RIGHT(str, n)`         | 从右侧取 n 个字符            |
| `SUBSTR(str, pos, len)` | 从第 pos 个开始取 len 个字符 |
| `LPAD(str, len, pad)`   | 左侧填充，实现右对齐         |
| `RPAD(str, len, pad)`   | 右侧填充，实现左对齐         |

### 去空格

- `TRIM()`：去除首尾空格
- `LTRIM()`：去除左侧空格
- `RTRIM()`：去除右侧空格
- `TRIM('o' FROM 'hello')`：去除指定字符

### 其他

| 函数                          | 说明                      |
|-------------------------------|---------------------------|
| `REPEAT(str, n)`              | 重复 n 次                 |
| `SPACE(n)`                    | 返回 n 个空格             |
| `STRCMP(a, b)`                | 比较大小，返回 1 / 0 / -1 |
| `LOCATE(substr, str)`         | 返回子串位置              |
| `ELT(n, str1, str2, ...)`     | 返回第 n 个字符串         |
| `FIELD(str, str1, str2, ...)` | 返回字符串所在位置        |
| `NULLIF(a, b)`                | 相等返回 NULL，否则返回 a |
