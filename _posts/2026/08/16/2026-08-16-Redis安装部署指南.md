> 下载地址/官网：[Redis Downloads](https://redis.io/downloads/)

Redis 后续可以承担验证码、登录态、接口幂等锁、热点数据缓存这类短生命周期数据。它不适合替代 MySQL 保存业务主数据，接入时要先想清楚
key 的命名、过期时间和淘汰策略。

### 端口和边界

| 端口 | 用途           |
|-----|----------------|
| 6379 | Redis 服务端口 |

本地学习可以监听 `127.0.0.1`。生产环境必须设置密码，不要把 6379 暴露到公网。

### Windows 安装说明

Redis 官方没有提供原生 Windows 安装包，这一节按“跳过原生安装”处理。

如果只是想在 Windows 本机调试，推荐两种方式：

1. 使用 WSL2 Ubuntu，按下面 Ubuntu 章节安装。
2. 使用 Docker Desktop 运行官方 Redis 镜像。

不建议使用来源不明的 Windows 修改版，后续版本、补丁和持久化行为都不可控。

### Ubuntu 安装部署 Redis

1. 更新索引并安装：

```bash
sudo apt update
sudo apt install -y redis-server
```

2. 确认版本和服务状态：

```bash
redis-server --version
sudo systemctl status redis-server --no-pager
```

3. 本机连通性测试：

```bash
redis-cli ping
```

看到 `PONG` 表示部署成功。

4. 设置访问密码：

```bash
sudo sed -i 's/^# requirepass foobared/requirepass your-redis-password/' /etc/redis/redis.conf
sudo systemctl restart redis-server
```

5. 使用密码验证：

```bash
redis-cli -h 127.0.0.1 -p 6379 -a 'your-redis-password' ping
```

6. 只监听本机时确认配置：

```bash
grep '^bind ' /etc/redis/redis.conf
```

期望看到 `bind 127.0.0.1 ::1`。

### macOS 安装部署 Redis

1. 安装：

```bash
brew install redis
```

2. 作为本机服务启动：

```bash
brew services start redis
```

3. 验证：

```bash
redis-cli ping
redis-server --version
```

4. 停止或重启：

```bash
brew services stop redis
brew services restart redis
```

Homebrew 默认只监听本机，适合开发环境。

### 生产部署建议

1. `requirepass` 必须设置，密码不要写进代码仓库。
2. `bind 127.0.0.1 ::1` 或只绑定内网地址。
3. 防火墙默认拒绝 6379，只允许应用服务器访问。
4. 缓存 key 统一加业务前缀，例如 `springvortex:mail:verify-code:*`。
5. 所有缓存 key 都要有过期时间，避免内存被慢慢吃满。
6. 打开 AOF 或 RDB 持久化前，先明确这块数据丢了能不能接受。

### 常见问题

`NOAUTH Authentication required` 表示服务已要求密码，连接时加 `-a` 或在应用配置里提供密码。

`Connection refused` 先检查服务是否启动、端口是否一致、防火墙是否拦截。

内存持续上涨通常是 key 没有过期时间或缓存穿透。先用 `redis-cli --bigkeys` 找大 key，再回到业务代码检查生命周期。
